# Sanjana Boutique

Premium, responsive boutique website for Sanjana Boutique.

## Current status
- Production-ready static frontend foundation
- Mobile responsive navigation
- Home, collections, story, services, gallery and contact sections
- Placeholder contact details intentionally left for the boutique's real information
- Domain can be connected later after the site is approved

## Next customization
Replace the placeholder WhatsApp number, Instagram handle, address, logo and gallery visuals with the boutique's real brand assets.

## Local preview
Open `index.html` directly in a browser, or serve the folder with any static web server.

## Deployment
This project can be hosted on GitHub Pages, Netlify, Vercel or another static host.
